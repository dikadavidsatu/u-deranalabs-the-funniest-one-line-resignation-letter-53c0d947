A resignation letter with the courage to be exactly one line long. Every bad workplace hides behind the slogan "we're a family here" — it is what a company says instead of paying people properly. This letter turns that slogan into the reason for leaving: the writer has found a job where the same sentence is treated as what it really is on Glassdoor — a warning sign, not a compensation package.

The program validates the letter against the one-line gate (single line, under 160 characters, opens with a salutation, actually resigns) and then prints it — one line, nothing else. Output is fully deterministic. When `MAKEFUN_OUTPUT_DIR` is set, the letter is also written to `entry.txt` in that directory.

## Run it

```sh
node main.ts
```
